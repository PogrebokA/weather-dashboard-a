# AGENTS.md — weather-dashboard-a

## О проекте

Статический погодный дашборд на HTML/CSS/JavaScript без сборки. Данные — Open-Meteo (геокодирование и прогноз), без ключа и регистрации. Только некоммерческое использование, обязательна атрибуция CC BY 4.0. Маршрут A, основная ОС — Windows.

## Команды

- Локальный запуск: `npm run dev` → `http://127.0.0.1:5173`
- Модульные тесты на фикстурах: `npm test`
- Живой smoke-тест API: `npm run test:live`
- UI-тесты: `npm run test:ui`

В PowerShell при заблокированном `npm.ps1` использовать `npm.cmd`.

## Правила изменений

- Не добавлять платные API, ключи, подписки, базы данных и тяжёлые серверы.
- Не подменять реальный прогноз демо-данными незаметно.
- Сохранять обработку пустого ввода, ненайденного города, сетевых ошибок, тайм-аута и отмены устаревших запросов.
- После изменений запускать релевантные тесты, затем полный набор; исправлять падения до показа результата.
- Тесты на фикстурах держать отдельно от живых запросов к API.
- Реальные команды, версии и результаты записывать в `JOURNAL.md`.
- Не публиковать учётные данные, токены и коды подтверждения.
